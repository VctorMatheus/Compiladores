CASOS DE TESTE - LINGUAGEM ROMAN++ (análise léxica, sintática e semântica)
=================================================================

Como usar:
  Copie o código de cada caso (o que vem depois da linha "---") para a IDE
  e clique em Compilar. O resultado deve bater com a linha "ESPERADO".
  "AVISO (linha N)" significa: compila, e a saída mostra um aviso na linha N.

  As linhas de erro são contadas a partir da primeira linha do código do caso.

Lembretes da gramática (Roman++.vgls):
  - Programa:     principium <funções> <comandos> terminus
  - Funções:      opus tipo nome(tipo p, tipo v[]) sic ... cis   (só no início do programa)
  - Procedimento: munus nome(...) sic ... cis                   ("reditus;" sem valor)
  - Blocos:       { ... }  ou  sic ... cis
  - si:           si (cond) fac { ... } aliter { ... }      (usa "fac", não "ergo")
  - Tipos:        atomus, fractio, caracter, logicum, catena
  - Lógicos:      et / &&, vel / ||, non / !
  - Unários:      non, !, ~, -   (podem ser repetidos: non non a, - -a)
  - Comentários:  // ... e /* ... */ (podem ter várias linhas; são descartados pelo léxico)

=== SS02 - Recursão e vetor como argumento
ESPERADO: SUCESSO
---
principium
  opus atomus fat(atomus n) sic
    si (n <= 1) fac { reditus 1; }
    reditus n * fat(n - 1);
  cis
  opus fractio media(fractio v[], atomus n) sic
    fractio s;
    atomus i;
    s = 0.0;
    pro (i = 0; i < n; i = i + 1) fac { s = s + v[i]; }
    reditus s / n;
  cis
  fractio notas[3];
  notas[0] = 7.5;
  notas[1] = 8;
  notas[2] = 9.25;
  inscribe(fat(5), media(notas, 3));
terminus
